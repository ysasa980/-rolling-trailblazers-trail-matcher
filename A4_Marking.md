## 1  | A4: MARKING DOCUMENT
This presentation should build on the previous work conducted by the project group. The presentation should describe the
architectural and design aspects of the project. There should also be documents describing:
- The functionality of the system and expected user interaction
- The current interface designs (is there any change from A3 and why)
- The system architecture with all the details of the current layers (front-end, back-end, database, or core technology)
- Prototype presentation of the current developed interactive system.
- The project’s branding and style guide
Groups also need to submit a basic working prototype demonstrating the current functionality of their system (including all
current code).
